# Hackathon Buddy Architecture

This document describes the high-level architecture of Hackathon Buddy.

## Frontend
- React.js with Vite
- Axios for API communication

## Backend
- Spring Boot (Java)
- REST APIs
- MySQL Database via Spring Data JPA

## AI Service
- Python FastAPI
- Responsible for Machine Learning algorithms: Teammate matching, Skill gap analysis, Recommendations, etc.
